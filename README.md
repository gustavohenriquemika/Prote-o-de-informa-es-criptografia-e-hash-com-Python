##  Desafio: Simulador de Força Bruta (Brute Force) com Progresso

Este script simula um ataque de força bruta criptográfico contra hashes SHA-256. O programa gera interações sequenciais de strings utilizando `itertools.product`, monitora o progresso em tempo real no terminal através de um contador de tentativas e interrompe a execução imediatamente ao encontrar uma colisão exata de hash.

### Como executar:
```bash
python forca_bruta.py
```
